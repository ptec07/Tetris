# Tetris (Zig + SDL2)

## 요구사항

이 프로젝트는 Zig로 작성된 데스크톱 테트리스 게임입니다.  
실행을 위해 아래 항목이 필요합니다.

- macOS 또는 Linux 개발 환경
- Zig 0.15.x
- SDL2
- SDL2_mixer

## 설치 (macOS, Homebrew)

```bash
brew install sdl2 sdl2_mixer
```

## 빌드

```bash
cd /Users/mingyuoh/AI_Workspaces/Tetris
zig build
```

## 실행

```bash
zig build run
```

게임은 SDL 창으로 실행되며 다음 입력을 지원합니다.

- 좌/우: `←` `→` (DAS/ARR 이동 지원)
- 소프트 드롭: `↓` (홀드)
- 회전: `Z`(좌회전), `↑` 또는 `X`(우회전)
- 하드 드롭: `SPACE`
- 시작/재시작: `ENTER`
- 일시정지: `P`
- 종료: `ESC`

## 오디오 정책

- BGM 경로: `assets/tetris.ogg`
- 파일이 없어도 게임은 실행되며 무음으로 동작합니다.
- 음원이 준비되면 아래 경로에 파일을 배치하면 됩니다.

```text
assets/tetris.ogg
```

예시 라이선스 규칙을 문서화하려면 사용한 음원 파일의 저작권/라이선스 정보를 동일 폴더의 `assets/` 하위에 기록하세요.

현재 저장소에는 배포 용량 이슈로 오디오 파일이 포함되지 않았습니다.  
음원 파일은 사용자의 프로젝트 정책에 맞는 라이선스 출처(예: 저작권 없는 BGM 또는 정식 배포 허가본)에서 별도로 준비하세요.

## 오디오 라이브러리 라이선스 체크포인트

SDL2 / SDL2_mixer는 시스템 라이브러리이며, 배포 시 사용 환경의 라이선스를 준수해야 합니다.

## 스모크 테스트(수동)

SDL 창 실행이 정상인지 확인하려면:

```bash
./scripts/smoke.sh
```

이 스크립트는 실행 직후 5초 뒤 프로세스를 종료하여 시작 시 크래시 유무를 확인합니다.

## 빌드·런타임 검증 체크리스트

- `zig build` 성공
- `./scripts/smoke.sh`에서 시작 직후 강제 종료까지 비정상 종료 없음
- 메뉴/일시정지/게임오버 상태 전환 시 BGM 상태 동기화
- 점수/레벨/라인/콤보 증가 시 오버플로우 보호(saturating 연산)
